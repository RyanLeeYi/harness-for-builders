# Harness for Builders：讓任何 AI agent 可靠地幫你把專案做完

> By [你的名字 / 連結]
>
> **你可以把整份文件丟給任何 AI,它就會帶你把 harness 建起來。**
>
> **v1.0** · 最後更新:YYYY-MM-DD · [Changelog](CHANGELOG.md)

---

Harness for Builders 是一套「AI coding agent 工作環境」的框架 —— 用 repo 裡的**結構化產物**(而不是越寫越長的 prompt)讓 agent 可靠:一個全新的 agent 打開 repo,就知道怎麼跑起來、做到哪了、接下來做什麼、怎麼算做完。

改編自 [Learn Harness Engineering](https://walkinglabs.github.io/learn-harness-engineering/zh-TW/projects/),形態參考 [Vault for Founders](https://github.com/cwlin0131/Vault-for-Founders)。
